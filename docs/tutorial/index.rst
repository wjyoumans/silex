Tutorial
========

These pages are workflow-oriented companions to the native C++ reference.
They use the same public API style as the compiled examples under
``examples/``: factory construction for mathematical parents, explicit status
checks, domain objects that keep parents alive, and named operations for
exact algebraic work.
