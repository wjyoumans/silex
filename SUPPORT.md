# Support

Silex is an early research-oriented 0.x library. Community support and fixes
are provided on a best-effort basis for the latest published release only,
without a response-time guarantee, service-level agreement, or production
support commitment.

Before asking for help:

1. Read the [stable documentation](https://wjyoumans.github.io/silex/0.1.1/)
   and [0.1.1 support matrix](https://wjyoumans.github.io/silex/0.1.1/support_matrix.html).
2. Check the [release notes](RELEASE_NOTES.md) and search existing
   [issues](https://github.com/wjyoumans/silex/issues) and
   [discussions](https://github.com/wjyoumans/silex/discussions).
3. Reproduce the problem with the latest published release in a supported
   configuration where possible.

Use [GitHub Discussions](https://github.com/wjyoumans/silex/discussions) for
usage and design questions. Use the
[bug report form](https://github.com/wjyoumans/silex/issues/new?template=bug.yml)
for reproducible defects and the
[feature request form](https://github.com/wjyoumans/silex/issues/new?template=feature.yml)
for proposed capabilities.

Include the Silex version, operating system, compiler, CMake and FLINT versions,
build options, exact command, and a minimal reproducer. Public reports should
not contain credentials, private data, or embargoed vulnerability details.
Report suspected security vulnerabilities privately as described in
[SECURITY.md](SECURITY.md).

Development documentation is published at
<https://wjyoumans.github.io/silex/dev/>, but the development branch is not a
supported release.
